# Icon Reference for Ultra

Ultra bundles **Maki** and **Temaki** icon sets as SDF sprites. Use them in symbol layers:

```yaml
icon-image: maki:bicycle    # or temaki:bicycle_parked
icon-color: blue             # recolorable because they're SDFs
```

Browse visually:
- Maki: https://labs.mapbox.com/maki-icons/
- Temaki: https://rapideditor.github.io/temaki/docs/
